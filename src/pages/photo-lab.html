Photo Lab

Every photo on the site goes through the same upgrade: straightened, smart-cropped, levelled, warmly graded and sharpened. Drag the sliders to compare the original with the finished version.

Every photo on the site is a real Horse & Hive photo. To replace one, save the new photo as photos/original/<slot>.jpg and run npm run photos -- <slot>, then npm run build.
